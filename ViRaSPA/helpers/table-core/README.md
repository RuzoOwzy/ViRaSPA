# table-core

Shared logic of `vs-table` and `vs-table-entry` (installed with them as a dependency): columns from `<column>` children, reading and formatting values (pipes such as `currency:'TZS'`), sorting, accent-insensitive search and filters, totals and CSV. `Viraspa.tableCore` - mostly for those components, usable on its own (`toCsv(rows, columns)`, `download(text, fileName)`).

- **0.1.0 (2026-11-08):** first version.
