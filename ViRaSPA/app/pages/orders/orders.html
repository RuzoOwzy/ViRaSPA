Orders

A list page built from vs-table: search, a status filter, sorting (Shift+click for several columns), selection with "Delete selected", double-click (or Enter) to open, a right-click menu, columns, export, totals and remembered settings. On a phone, rows turn into cards.

The same table with the server

Paging, sorting and search go to the server (the public demo API's posts); the table only shows what comes back.
